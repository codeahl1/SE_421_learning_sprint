Try these experiments

  1. Select 8 bits and unsigned. Try 255 + 1.
  2. Select signed. Try 127 + 1. Notice the leading bit.
  3. Select 4 bits. Predict the result of unsigned 15 + 1.
  4. Set the amount to add to zero. Does overflow occur?

With n bits, only 2ⁿ different patterns are available. Unsigned values range from 0 to 2ⁿ − 1. Two's complement signed values range from −2ⁿ⁻¹ to 2ⁿ⁻¹ − 1.

Model limitation: This app deliberately simulates fixed-width wrapping. JavaScript does not ordinarily add numbers as 4-bit or 8-bit integers. In C and C++, signed integer overflow is undefined behavior; this simulated signed wrap is not a guarantee of those languages.
